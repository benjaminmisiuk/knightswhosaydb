## Tutorial: Backscatter mosaicking

This tutorial demonstrates the functionality of the knightswhosaydb package for mosaicking multibeam echosounder data, including multifrequency backscatter. 
The [mosaicking.ipynb](https://github.com/benjaminmisiuk/knightswhosaydb/blob/4023679927d0e31a4c238b920ff2f0161f61f11c/tutorials/2_Mosaicking/mosaicking.ipynb) file contains the full tutorial.
