## Tutorial: Backscatter mosaicking

This tutorial demonstrates the functionality of the knightswhosaydb package for mosaicking multibeam echosounder data, including multifrequency backscatter. 
The [mosaicking.ipynb](https://github.com/benjaminmisiuk/knightswhosaydb/blob/main/tutorials/2_Mosaicking/mosaicking.ipynb) file contains the full tutorial.
